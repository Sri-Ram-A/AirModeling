Step 1 of 6
What is a Gaussian Plume?
Imagine a factory chimney releasing smoke. The wind carries it downwind while turbulence spreads it outward — sideways and vertically. This spreading follows a bell-curve (Gaussian) shape in both directions.
The canvas shows the plume as a colour field — darker orange means higher concentration. You are looking from above (top-down). The source is the black dot at the centre.
Try rotating the Wind direction slider. The plume always points downwind from the source — it cannot blow upwind.
The spreading width is controlled by the stability class (A–F). Think of it as how turbulent the atmosphere is:
  • AVery unstable — hot sunny day, strong mixing. Plume spreads very wide, lower peak concentration.
  • DNeutral — overcast or moderate wind. Medium spread.
  • FStable — calm night. Plume stays narrow, concentration stays high along centreline.
// Ground-level concentration at a point (x, y) C(x,y) = Q / (π·u·σ_y·σ_z) × exp(−y² / 2σ_y²) ← lateral Gaussian × exp(−H² / 2σ_z²) ← vertical dilution
The stack height H matters: taller stacks release pollution higher up. The term exp(−H²/2σ_z²) shrinks as H grows — meaning less of the plume reaches the ground near the source.
σ_y is the lateral (crosswind) spread in metres. σ_z is the vertical spread. Both grow as distance increases. Adjust the sliders — notice how the plume footprint changes shape.
Step 2 of 6
Distance & Bearing Between Stations
Before any physics, we need to know how far apart two stations are and in which direction. This is pure geometry on the curved surface of the Earth.
The canvas shows your 14 Bangalore monitoring stations. The green dot is the source; the red dot is the receptor. A line connects them.
Haversine Formula
The Earth is a sphere, so simple Pythagoras gives the wrong answer for distances longer than ~1 km. The Haversine formula gives the true great-circle distance:
a = sin²(Δlat/2) + cos(lat1)·cos(lat2)·sin²(Δlon/2) d = 2R · arcsin(√a) // R = 6371 km
Drag the Rec lat / Rec lon sliders. Watch the distance and bearing update in the readout box. The line on the canvas rotates to match.
Bearing Formula
Bearing is the compass direction from the source to the receptor, measured clockwise from North (0° = North, 90° = East, 180° = South).
θ = atan2( sin(Δlon)·cos(lat2), cos(lat1)·sin(lat2) − sin(lat1)·cos(lat2)·cos(Δlon) ) mod 360°
These two numbers — d (distance) and θ (bearing) — are the raw geometric inputs to the Gaussian Plume model. Nothing atmospheric yet.

Projecting onto the Wind Frame
The Gaussian Plume model needs distance along the wind direction, not compass direction. We rotate the geometry into the wind's own coordinate system.
Think of it like this: the wind defines a new "x-axis" pointing downwind. We project the source→receptor vector onto this axis.

If x ≤ 0, the receptor is upwind of the source. The plume cannot travel backward. We immediately set Tij = 0 and stop. This is why ~50% of all matrix entries are zero!
On the canvas, the blue arrow is the wind direction. The green arrow is the downwind axis (x). The orange dashed line is the crosswind axis (y).
Try setting Wind dir = Bearing. The receptor lands exactly on the centreline (y = 0). This is where concentration is highest — maximum exposure.
Now set Wind dir = Bearing + 90°. x becomes zero → T = 0. The wind blows perpendicular to the receptor so the plume misses it entirely.
Step 4 of 6
Dispersion Widths σ_y and σ_z
Once we know x (downwind distance), we compute how wide the plume has grown at that point. This uses empirical power-law formulas fitted to real field measurements.
Think of σ_y and σ_z as the standard deviation of the bell-curve in the crosswind and vertical directions. Larger σ = wider, more diluted plume.
σ_y(x) = a_y · x^b_y // crosswind spread [m] σ_z(x) = a_z · x^b_z // vertical spread [m] (capped at 500 m)

Why stability matters here
Each stability class (A–F) has different a, b coefficients. Class A has large coefficients → very wide plume quickly. Class F has small coefficients → narrow plume that travels far without diluting.
The vertical term exp(−H²/2σ_z²) tells you how much of the plume has mixed down to ground level. When σ_z ≫ H, nearly all of it has. When σ_z ≪ H, the plume is still aloft and the ground sees almost nothing.

Step 5 of 6
Computing One Tij Element
We now combine all previous steps into a single number: the transport coefficient Tij. It answers: "If source j emits 1 g/s, what concentration does receptor i see?"
T_ij = (1 / π·u·σ_y·σ_z) × exp(−y² / 2σ_y²) ← lateral factor × exp(−H² / 2σ_z²) ← vertical factor × 1e6 ← g/m³ → µg/m³

Three independent effects multiply together:
• Dilution: the plume is spread by turbulence — more σ = lower T
• Lateral: how far off the centreline is the receptor?
• Vertical: how much has the plume descended to ground?
  • →Higher wind speed u → larger denominator → T drops
  • →Receptor on centreline (y=0) → lateral factor = 1.0 (maximum)
  • →Taller stack H → vertical factor → 0 (plume aloft)
  • →Unstable class A → large σ → T drops quickly with distance
Step 6 of 6
The Full Transport Matrix C = T · Q
We repeat the Tij calculation for every pair of the 14 stations. The result is a 14×14 matrix. Each cell tells how much one station influences another.
The canvas shows the matrix as a heatmap. Each row is a receptor (sensor), each column is a source. Bright = high transport coefficient. Grey = zero (upwind).
C = T · Q // the core equation C ∈ ℝ¹⁴ // measured concentrations [µg/m³] T ∈ ℝ¹⁴ˣ¹⁴ // transport matrix Q ∈ ℝ¹⁴ // unknown emission rates [g/s]
Rotate the wind direction. Watch whole rows and columns switch between active (coloured) and zero (grey). Wind controls which sources can even reach which receptors.
Why inversion is hard
To find Q (emission rates), we need to invert this equation: Q = T⁻¹ · C. But T is severely ill-conditioned because:
  • 1Many zeros: upwind pairs give T=0, making the matrix rank-deficient.
  • 2Huge range: nearby downwind pairs have T ≫ 1; far crosswind pairs T ≈ 0. Condition number κ = σ_max/σ_min is enormous.
  • 3Non-negative Q: emission rates can't be negative, so plain matrix inversion fails physically.
This is why we need NNLS (non-negative least squares), Tikhonov regularisation, or Bayesian inference — not naive matrix inversion. Each method handles the ill-conditioning differently.
